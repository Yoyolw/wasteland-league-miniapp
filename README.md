# Лига Пустоши — прототип Telegram Mini App

Статическая HTML5-игра по правилам «Лиги Пустоши»: скрытый одновременный выбор стихии
(Природа → Вода → Огонь → Природа), три испытания и дуэль с компьютером.

Прототип. Это не Roblox-версия и не связано с её профилями.

## Конфиденциальность

Игра не собирает и не отправляет никаких данных. Прогресс хранится только в `localStorage`
на устройстве игрока и удаляется вместе с данными сайта или Telegram. Данные аккаунта Telegram
не читаются. Подключается только официальный скрипт `telegram.org/js/telegram-web-app.js`.

## Запуск

Откройте `index.html` через любой HTTP-сервер. Тесты движка — `tests.html`.
